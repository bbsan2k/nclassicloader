# Flag assets

`jp.svg`, `eu.svg`, and `us.svg` are the Japan, European Union, and United
States flag SVGs from [flag-icons](https://github.com/lipis/flag-icons),
at upstream commit
[`ac7e0eb3259eb62aa6100c435607e2fe03896a97`](https://github.com/lipis/flag-icons/tree/ac7e0eb3259eb62aa6100c435607e2fe03896a97).
They are distributed under the MIT License reproduced in `LICENSE.txt` and
rendered from these embedded source assets at runtime. The unknown-region marker
is neutral UI chrome, not a flag.
